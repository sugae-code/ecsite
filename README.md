# はこ便ものさし — 無料の梱包サイズ計算ツール

**公開サイト: https://hakopita-m84e27.deed.page/**

- [メルカリ便の送料・梱包サイズを比較](https://hakopita-m84e27.deed.page/compare.html)
- [宅急便60・80・100サイズの箱選びガイド](https://hakopita-m84e27.deed.page/box-guide.html)
- [梱包資材・配送関連の広告提携相談](https://hakopita-m84e27.deed.page/advertise.html)

縦・横・高さ・緩衝材の余裕と梱包後の重さから、ヤマト宅急便／日本郵便ゆうパックのサイズ区分を計算する日本語の無料ツールです。

- 会員登録・インストール不要、スマホ対応
- ブラウザ内で計算（寸法情報を外部送信しません）
- 宅急便の重量によるサイズアップと、ゆうパック25kg上限を考慮
- 送料・発送可否は実際の梱包外寸と公式情報を確認してください

## 継続運用

ソースコードはこのリポジトリにありますが、**サイトの公開先はGitHub Pagesではなく独立したdeed.pageです**。更新は非公開の配備ジョブが差分を検知して反映します。計算ロジックの単体テスト:

```sh
node --test test.mjs
```

規格変更時には公式サイトの規格を確認し、`calc.mjs` を修正してください。
